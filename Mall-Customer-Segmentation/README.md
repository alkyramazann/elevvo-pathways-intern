# Customer Segmentation using K-Means Clustering

Mall Customers dataset (200 customers) - segments by Annual Income and Spending Score.

## Files
- `Mall_Customer_Segmentation.ipynb` - full project with explanations and saved outputs (open in Jupyter)
- `customer_segmentation.py` - same analysis as a plain script
- `Mall_Customers.csv` - input data
- `Mall_Customers_clustered.csv` - data with K-Means and DBSCAN labels and segment names
- `figures/` - all plots as PNG

## Run
```
pip install -r requirements.txt
jupyter notebook Mall_Customer_Segmentation.ipynb     # or: python customer_segmentation.py
```
Run from this folder so `Mall_Customers.csv` is found.
